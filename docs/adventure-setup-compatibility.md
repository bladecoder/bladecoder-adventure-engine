# Setup compatibility evidence

The bundle reports its paired engine, dependency versions and independent
source fingerprints for the generator, templates and toolkit. Generation and
toolkit updates reject a different engine version. Toolkit updates do not migrate
engine dependencies, launchers, game sources or project recipes.

| Environment / capability | Current evidence | Limit |
| --- | --- | --- |
| Linux, Java 21, paired 4.5.0-SNAPSHOT | Standalone generation, consumer desktop build and native HTTP smoke executed | Java 8 is the compilation target; a Java 8 runtime has not been exercised |
| Headless generation, desktop only | Executed with display and Android SDK variables removed | Consumer build resolves dependencies separately |
| Desktop two-button, pie, single-click | Packaged input, dialogue, inventory, save/load scenarios executed | Default starter coverage only |
| Optional Ink disabled, nondefault viewport | Packaged native scenario executed | Does not certify arbitrary game content |
| External art root, spaces / Unicode | Inkscape exports and reviewed apply executed | Artist-local root must be selected explicitly |
| Optional audio | MP3 stereo and PCM16 mono/stereo WAV generation and native capture executed | Capture needs Linux Pulse/PipeWire; listening remains a human check |
| Optional cutout Spine | Actual skeleton/atlas, animation and save/load probes executed | Mesh/constraint authoring unsupported; licensed Spine installation is separate |
| Android / iOS scaffolding | Generated by the shared API | No device build/playback certification |
| macOS / Windows | Portable generation code and wrappers supplied | Native process ownership/capture and actual builds not yet verified |
| GitHub CI | Phase 1 build passed for `b9f10d86`; setup Gradle build and consumer CI passed for `4a84bf22` ([phase 1](https://github.com/bladecoder/bladecoder-adventure-engine/actions/runs/39959816579), [setup build](https://github.com/bladecoder/bladecoder-adventure-engine/actions/runs/39958487302), [consumers](https://github.com/bladecoder/bladecoder-adventure-engine/actions/runs/39958487264)) | Verifies both branch snapshots; no release was published |
| Published setup release | Not published | A local bundle is not evidence of a hosted release |

Executed evidence and limitations are retained in `adventure-setup-validation.md`
and the domain-specific validation JSON documents. Snapshot artifacts can change
without a version change: retain the actual bundle/package hashes with test
results. Re-run relevant checks after updates and after adopting project-specific
content. Pixel baselines require explicit environment-specific image review.
